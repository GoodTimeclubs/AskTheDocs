# Urlaubsrichtlinie – Version 2.0

**Gültig ab:** 01.01.2026
**Ersetzt:** Version 1.3 vom 01.04.2022
**Verantwortlich:** Personalabteilung, Ansprechperson: Mira Lindqvist

## 1. Urlaubsanspruch

Alle Mitarbeitenden in Vollzeit haben Anspruch auf **30 Urlaubstage** pro Kalenderjahr. Teilzeitkräfte erhalten den Anspruch anteilig zu ihren Arbeitstagen pro Woche.

Ab dem fünften Jahr der Betriebszugehörigkeit kommt **ein zusätzlicher Tag** hinzu, ab dem zehnten Jahr **zwei zusätzliche Tage**.

## 2. Beantragung

- Urlaub wird über das HR-Portal „Polaris" beantragt.
- Anträge bis 3 Tage: mindestens **1 Woche** im Voraus.
- Anträge über 3 Tage: mindestens **4 Wochen** im Voraus.
- Die Führungskraft muss innerhalb von 5 Werktagen entscheiden.

## 3. Übertrag

Nicht genommener Urlaub kann bis zum **31. März** des Folgejahres übertragen werden. Danach verfällt er, sofern er nicht aus betrieblichen Gründen oder wegen Krankheit nicht genommen werden konnte.

## 4. Sonderurlaub

| Anlass | Tage |
|--------|------|
| Eigene Hochzeit / eingetragene Partnerschaft | 2 |
| Geburt eines Kindes (für den zweiten Elternteil) | 2 |
| Umzug | 1 |
| Tod eines nahen Angehörigen | 3 |

## 5. Betriebsferien

Zwischen dem 24.12. und dem 01.01. ist der Standort Leipzig geschlossen. Dafür werden 3 Urlaubstage automatisch verbucht.
